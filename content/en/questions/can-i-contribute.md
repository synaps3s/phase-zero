title: "I found something wrong. Can I fix it?"
order: 230
topic: catalogue
---

Yes, and a wrong date you noticed is a real contribution even if you never touch
the code.

The whole site is one public repository. Every page has an edit link at the
bottom that lands on the exact file behind it. Fixing a fact is editing one file,
adding the source, and opening a pull request, which can be done entirely in a
browser.

Translating is the same shape and needs no coding at all: copy a file from the
English directory, translate the sentences, open a pull request. Adding a whole
new language is one entry in a config file and a new directory. If it ever looks
like you need to change code to add a language, that is a bug in the code.
